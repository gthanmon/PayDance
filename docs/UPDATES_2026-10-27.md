# 任务栏增强版更新说明

日期：2026-10-27

本次更新新增任务栏收入显示与自动工作日历，并改进时间输入兼容性和设置保存体验。本分支基于 PayDance 0.9.10，是非官方修改版本，保留原项目版权与 AGPL-3.0-only 许可。

## 新增功能

- **任务栏收入显示**：在 Windows 任务栏查看实时收入，双击打开主界面，右键访问设置等常用操作。
- **收入悬停详情**：展示今日收入、预计收入、工作进度、剩余时间和薪资换算信息。
- **自动工作日历**：支持双休、单休和大小周，结合中国法定节假日与调休安排计算当月工作日。
- **日历预览与缓存**：支持查看月历，使用内置日历数据，并缓存联网更新结果。

## 体验改进

- 支持任务栏显示位置调整，自动保存相关偏好。
- 优化任务栏布局、窗口唤起与后台运行体验。
- 为新增功能提供中英文界面与提示。

## 问题修复

- 修复部分 Windows 时间输入被误判为无效的问题，兼容包含秒和小数秒的时间格式。
- 修复特定任务栏布局下的挂载失败和显示位置异常。
- 修复水平偏移设置在重启后恢复默认值的问题。

## 使用与升级

- 任务栏显示适用于 Windows 主屏幕的水平任务栏。
- 内置日历覆盖 2025、2026 年；缺少对应年度的有效数据时，界面会将工作日计算标记为暂估。
- 升级前退出正在运行的旧版，并备份现有配置；已有有效设置可继续使用。
