# 任务栏增强版更新说明

日期：2026-10-27

本次更新整合本分支对上游 PayDance 0.9.10 的修改，围绕任务栏显示、工作日计算和 Windows 使用体验展开。这是由 gthanmon 维护的非官方修改版本，保留原项目版权和 AGPL-3.0-only 许可。

## 新增功能

### 任务栏实时金额

将今日已赚金额显示在主屏幕的水平任务栏中，可收起原来的悬浮窗。任务栏重建后会尝试恢复挂载；金额显示正常时隐藏额外托盘图标，显示失败或主动关闭该功能时恢复托盘入口。

- 双击金额打开主页面，并退出迷你模式、关闭设置等面板。
- 右键提供主页面、设置、隐藏主窗口、迷你模式、置顶和退出菜单。
- 菜单使用 Windows 原生菜单，打开菜单时不会先打开主窗口，也不会阻塞金额更新。

### 悬停收入详情

鼠标移到任务栏金额上，可查看：

- 今日已赚和今日预计收入。
- 当前工作状态、已工作时间、总工作时间和进度。
- 距离上班、午休结束或下班的剩余时间。
- 上下班、午休及跨午夜班次的工作日期。
- 薪资模式、折算时薪、秒薪和当月工作日信息。

### 自动计算当月上班天数

工作日计算支持“手动”和“自动计算”两种模式。自动模式新增：

- 双休：按每周休息两天排班。
- 单休：可指定每周休息日。
- 大小周：可指定基准周及该周为单休或双休，跨月连续计算。

中国法定节假日和调休补班安排优先于每周排班。月历预览标记工作日、休息日和调休日期；月薪按实际月份的工作日数换算，夜班按班次开始日期归属月份。

内置 2025、2026 年日历。联网获取后续安排后会缓存，离线时继续使用已有数据；日期、年份或年度完整性验证不通过时保留本地有效数据。未知年份显示“暂估”，仍可切回手动模式。

### 静默开机启动

开机通过 `--autostart` 启动时直接进入后台，不显示主窗口；手动打开程序或双击任务栏金额时才显示主页面。

自启固定指向 `C:\Program Files\paydance\PayDance.exe`。从该位置运行新版后，已启用的旧自启项会迁移到固定路径并清理已知旧项；未启用自启的用户保持原状态。以后覆盖同名文件即可让自启使用新版。

## 修复与体验调整

- **时间格式**：修复 Windows 时间控件返回带秒时间时提示“上班时间错误”的问题，上下班和午休支持 `HH:mm`、`HH:mm:ss` 及毫秒，收入计算保留相应精度。
- **任务栏创建超时**：避免直接在 Explorer 上跨进程创建窗口导致 `CreateWindowExW failed (1460)`。
- **字体与位置**：金额使用微软雅黑 10 磅常规字体，自动排在 TrafficMonitor 左侧，并按文字实际宽度缩小间距。
- **反复左移**：修复 PayDance 和 TrafficMonitor 相互调整任务列表区域，导致两个控件持续向左移动的问题。
- **水平偏移**：支持 `-2000` 至 `2000`，正数左移、负数右移；输入改动立即写盘，关闭窗口前也会保存，修复重启后数字归零。
- **配置迁移**：继续保留原有有效配置和手动工作日设置，不要求重新填写工资和工作时间。
- **中英界面**：为新增设置、校验、月历及悬停详情补齐中英文文案。
- **构建入口**：新增 `npm run build:exe:enhanced`，输出 `PayDance.exe` 与 SHA256 文件；增强版构建关闭官方自动更新检查，防止更新后丢失本分支功能。

## 升级方法

1. 完全退出旧版。
2. 将新版复制并覆盖到 `C:\Program Files\paydance\PayDance.exe`。
3. 从该位置运行一次，确认“显示实时金额”已开启；需要开机启动时在设置中开启。
4. 以后更新继续覆盖同名文件即可。

配置仍保存在 `%APPDATA%\com.masterbao.paydance\salary-settings.json`。建议升级前备份；两个版本共用设置与单实例标识，不能同时运行。
